# Contributing

- Issue/Bug: aprire issue con minimo riproducibile.
- Feature: PR piccole, test-first, nessun cambio di contratti senza documento.
- Regole di codice: deterministic-first (l'LLM non decide mai i calcoli);
  epistemica esplicita; mai dati reali privati nei repo pubblici.
- Licenze: nuove dipendenze dati devono avere licenza chiara (MIT/CC-BY/open) con NOTICE.
